# versio-granulita-navigator

travelers guide for voice resynthesis: a one-page reference for **granulita versio**, the noise engineering granular chord resynthesizer firmware for the versio platform. every knob by its number on the numbered panel, all sixteen chords drawn out, verb, the hit modes, patches and specs.

source: the noise engineering granulita versio manual.

part of the [versio starsystem](https://mellotom.github.io/versio-navigator/) in the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with noise engineering.
